Generated 2026-10-29 11:37 UTC by `python -m labelguard.evaluation --write docs/EVALUATION_REPORT.md`. Re-run it on your own machine to get numbers for that machine.

> **What this is and is not.** The labels are fictional and generated by this project's own code, the ground truth was written by the project author, and the corpus is small. These numbers show that the rules behave as intended on these cases and that nothing regressed. They are **not** an estimate of accuracy on real labels, they have no statistical significance, and they do not say anything about regulatory compliance.

## Definitions

- **Unit of evaluation:** one (label pair, rule) combination.
- **Positive finding:** a rule whose result is *flagged* for the pair. Results of *not evaluated* ("could not be verified") are not positives and not negatives; they are checked separately (see below).
- **Ground truth:** for each pair, the set of rule ids that *should* be flagged, written from what the injected change means and from the rule descriptions in `config/rules.toml`, before the case was run. A pair with no change has an empty set.
- **TP** flagged and expected; **FP** flagged but not expected; **FN** expected but not flagged. **Precision** = TP/(TP+FP). **Recall** = TP/(TP+FN). **F1** = 2PR/(P+R). True negatives are not counted (their number depends only on how many rules exist).
- **Exact case:** a pair with no FP and no FN.

## Corrections to the ground truth

Two Day 4 expectations were wrong in the first draft and were corrected after the first run. They are listed so the correction is visible. The engine was not changed.

- 'manufacturing date removed': first draft expected R-DATE-002 and R-REQ-008. R-REQ-008 ships with enabled = false (the manufacturing date is not configured as required), so the engine's output (R-DATE-002 only) was right. Counted in the first run as 1 false negative.
- 'multi-page label, page 2 text changed': first draft expected R-TEXT-001 + R-TEXT-002 (added + missing). The rules file has a dedicated 'Text modified' rule, R-TEXT-003, for a reworded line, which is the better reading of this change. Counted in the first run as 1 false positive and 2 false negatives.
- Totals on the first run, before these two corrections: TP 38, FP 1, FN 3 (precision 0.974, recall 0.927, F1 0.950). The corrected corpus gives a perfect score because the corpus is small and its author also wrote the ground truth; treat that as a regression baseline, not as evidence of accuracy.
